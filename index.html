Final-Year Thesis

FLAGSHIP PROJECT

QuantLab — Modular Event-Driven Backtesting Platform

Bachelor's thesis · Python, Flask, SQLite, Plotly.js, Pandas, NumPy

QuantLab is a market-agnostic backtesting engine with a full web dashboard, built to let a user configure a trading strategy, run it bar-by-bar against historical data with zero look-ahead bias, and analyze the results through 12 performance metrics and interactive charts. The system is designed in three layers — an engine that processes market data sequentially and enforces strict data-access rules, a strategy layer using an abstract base class so new strategies can be added without touching the engine, and an analytics layer computing everything from Sharpe ratio to session-based P&L breakdowns.

Engineering highlights
